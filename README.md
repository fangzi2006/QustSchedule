# 青科课表通

青岛科技大学教务（新正方）课表客户端，Flutter 编写，Windows 与 Android 共用一套代码。

登录一次后课表离线可看；Cookie 过期会用保存的密码自动重登，需要验证码时弹出验证码页。

## 功能

- **免登与自动重登**：保存学号密码，下次打开直接进课表。会话失效自动重登；连续失败会熔断，避免把账号锁掉。
- **周视图课表**：按周查看，表头带真实日期、今天高亮；支持单双周与 `1-16 周` 这类周次过滤。
- **课程详情**：点格子看教师、地点、节次、周次、教学班、学分。
- **多套作息时间表**：可存多张（如夏季 / 冬季），按生效日自动切换；支持逐节改时间与快捷批量设置。
- **调课**：把某月某日的课整体调到另一天；时间冲突时在表头提示并可查看被顶掉的课。原始课表数据不变，只影响显示。
- **课表备注**：教务课表下方的"实践课程 / 其他课程"，可在设置里开关。
- **离线缓存与后台刷新**：冷启动先显示上次的课表，再静默更新。
- **外观**：课表格子高度、卡片文字大小可调。
- **调试信息**：请求记录、原始响应、解析结果，出问题时可一键复制。

## 使用

### 首次使用

1. 输入学号与密码登录。密码存入系统安全存储（Android Keystore / Windows DPAPI），只用于后续自动重登。
2. 登录成功直接进入课表，同时缓存到本地。
3. **校准周次**：教务不提供开学日期，app 先按学期估算。点课表页右上角「⋯」→「校准当前周次」，填"本周实际是第几周"。
4. **核对作息**：设置 →「作息时间表」→「课表节数」改成自己班级的节数，再逐节确认上课时间（默认是 10 节课的常见作息）。

### 日常查看

- 左右滑动或点顶部箭头切周；不在本周时右下角出现「今」按钮，点一下回到本周。
- 点课程格子看详情。
- 右上角刷新，重新登录与报错都在右上角的状态弹窗里，不会把已显示的课表换成错误页。
- 右上角「⋯」：校准周次 / 作息时间表 / 教务地址 / 调课 / 外观。
- 底部 dock 切到设置页：显示教师与地点、显示课表备注、静默更新、账号、调试信息、开源许可。

### 换设备或重装

密码存在系统安全存储里，换机、重装后需要重新登录一次；课表与作息表会重新拉取。

## 技术栈

- **Flutter 3.x / Dart 3.13**，Material 3，只做浅色主题。
- **平台**：Windows（CMake + MSVC）、Android（minSdk 24 / compileSdk 37）。
- **运行时依赖只有三个**：`flutter_secure_storage`（存密码）、`path_provider`（Cookie 与缓存目录）、`cupertino_icons`。
- **教务协议层零 Flutter 依赖**：HTTP 客户端（手动重定向 + 白名单 + 限速）、Cookie 存储、HTML 取值、RSA 密码加密、课表解析均为自行实现，只依赖 `pointycastle` 与 `crypto`，因此可以脱离 UI 单独测试。
- **测试**：`flutter test`，界面与状态机 194 个用例 + 协议层 72 个用例，全部离线（协议层用合成教务服务端对拍）。

## 已知限制

- 只支持青岛科技大学使用的**新正方**教务系统。统一认证（CAS）与旧版/其他厂商系统会明确报错，不会静默失败。
- 周次需要手动校准一次（教务不提供开学日期）。
- 只有浅色主题。
- 同一门课若教务按不同周次拆成多行（如 `1-8周` 与 `9-16周` 各一行），周视图显示正常，但课程详情只展示其中一行。
